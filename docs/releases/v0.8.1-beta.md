This release fixes what Claude profiles share with your main account. Some of what Claude Code
keeps for one account or one org was linked into every profile.

## Fixes

- Claude Code keeps state for the signed-in account and its org in its config folder:
  - the org's policy limits and managed settings (`policy-limits.json`, `remote-settings.json`);
  - which MCP servers and connectors need you to sign in (`mcp-needs-auth-cache.json`);
  - `state/`, its caches and its telemetry.

  clausona linked all of these into every Claude profile. So a profile on another account read
  your main account's until Claude Code saved its own, and then `clausona doctor` showed
  `… replaced an expected shared link`. Each profile now keeps its own. Sessions, history,
  settings, skills and everything else that carries across accounts are shared as before.
- The background daemon's files (`daemon.json`, `daemon/` and the rest) were shared too. A
  scheduled task set up on one account could then run again on every account whose daemon
  started. Each account now has its own daemon and its own scheduled tasks.
- Claude Code's backups of the account file were shared, so a lost `.claude.json` could come
  back from another account's copy. Each profile now keeps its own. If your main account's
  `backups/` still holds another account's copies, `clausona doctor` says so and how to remove
  them.

## After updating

Run `clausona doctor` to see which Claude profiles still have the old links, then
`clausona repair <profile>` for each one. Repair removes the links and leaves your main
account's files where they are. If a profile runs a background daemon (`claude daemon`), stop it
there first; repair tells you if you haven't.

A scheduled task or Remote Control folder that you added from a profile while it shared the
daemon's settings stays with your main account.
[How it works](https://github.com/larcane97/clausona/blob/main/docs/how-it-works.md#what-a-claude-profile-shares)
says how to move it.

## Updating

Choose Update on the dashboard, or run `clausona update`. Your shell hook hasn't changed, so open
shells keep working.

On 0.3.0-beta or earlier, which can't update itself, run the installer again:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
