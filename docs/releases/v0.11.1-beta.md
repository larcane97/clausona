This release fixes how a fleet notices that a worker has finished. The coordinating session could
miss a worker's DONE line for hours, and leave a finished task running. The line had scrolled off
the screen, was cut from what the runner kept, or was gone after the worker compacted. The
`clausona` command itself hasn't changed.

## Fixes

- A Claude Code worker that sat idle looked unfinished. Claude Code compacts an idle conversation
  before its prompt cache runs out ("Compacted while idle"), and the worker's last reply is then
  gone from its screen. A coordinator that came back to it late found no DONE line. Now it reads
  the reply from what the runner keeps first. Failing that, it reads Claude Code's own session
  file, through a small script in `fleet-core`. Only then does it read the screen. herdr keeps no
  record of replies, so there the session file is the source. (#201)
- In Superset, a long report was never seen. Reading a Superset terminal returns only the rows it
  shows, whatever `--max-lines` asks for. A worker's report starts with its `SUPERSET_WORKER_DONE`
  line, so a report taller than the screen lost that line off the top. When a worker stops, the
  coordinator now gets its last message from Superset's record of the session, and it can read the
  whole record. (#199)
- In tmux, the DONE line of a long reply was cut. The coordinator got the first 4000 characters of
  a worker's last reply, and the DONE line is the last one. It now gets the end. (#200)

Claude Code in full-screen mode keeps no scrollback, so in tmux and herdr too, reading more lines
than the screen holds gave nothing more. These fixes don't depend on the screen.

## Updating

Plugins come from the marketplace, not from `clausona update`. fleet-core and all four runners have
new versions. Update fleet-core and the runners you use, then start a new Claude Code session:

```bash
claude plugin marketplace update clausona
claude plugin update fleet-core@clausona
claude plugin update superset-fleet@clausona   # or tmux-fleet, herdr-fleet, orca-fleet
```

In Codex, run `codex plugin marketplace upgrade clausona`, then `codex plugin add <plugin>@clausona`
for fleet-core and each runner you use.

For the `clausona` command, choose Update on the dashboard, or run `clausona update`. Your shell
hook hasn't changed, so open shells keep working.

On 0.3.0-beta or earlier, which can't update itself, run the installer again:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
