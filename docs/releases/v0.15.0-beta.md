This release shows each account's subscription plan next to the account. The update question after commands no longer holds updates off when you don't answer it.

## Plans next to accounts

`clausona list` now puts each account's plan in brackets after the account:

```
PROFILE             ACCOUNT                      5H         7D
claude:work         you@example.com (Max)        6% 23m     46% 13h
claude:personal     you@personal.com (Pro)       0%         100% 4d
codex:work          you@example.com (Pro Lite)   none       12% 5d
```

For a Claude account this is the plan Claude Code saved with the sign-in, such as Ultra, Max or Pro. For a Codex account it is the ChatGPT plan, such as Plus or Pro. clausona reads it from disk, so it also shows with `--no-quota` and needs no extra request.

`clausona current` shows the plan after the account in the same way. On the dashboard it follows the account in the Profiles list and in the profile panel. In the `--json` output of `list` and `current`, each profile has a new `plan` field.

An API profile has no plan, and neither does an account that Claude Code has not saved a plan for. A row that says `other account` shows none either, because the plan on disk belongs to that other account. In a narrow terminal the email is cut and the plan stays. See [plan quota](https://github.com/larcane97/clausona/blob/main/docs/plan-quota.md). (#229)

## The update question waits for an answer

When a newer release is out, commands such as `clausona list` ask `Update now? (Y/n)` after their output. If you didn't answer within 10 seconds, that used to count as a no, and you weren't asked again for 7 days, even when newer releases came out in the meantime. Now the command just finishes and prints `No answer. You'll be asked again next time.`, and the next command asks again. A no, by `n` or any key other than `y` or Enter, still holds the question for 7 days. (#230)

## Updating

To update, choose Update on the dashboard or run `clausona update`. If you installed with npm, run `npm install -g clausona@latest`.

Versions 0.3.0-beta and earlier cannot update themselves. Run the installer again instead:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
