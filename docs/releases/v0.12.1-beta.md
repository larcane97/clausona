This release fixes two ways clausona could show you one account's state as another's: plan quota
read with another account's sign-in, and plugin versions that drifted apart between profiles.

## Quota that belonged to another account

`csn list` and the dashboard could show one account's quota on another profile's row. A profile's
sign-in can end up being another account. Claude Code may ask you to `/login` in a session that runs
on a different profile than you think, and the browser is signed in to the account you meant to use.
The row then showed that account's 5H and 7D next to the profile's own email, so `claude:default`
and the account you were working in could list exactly the same numbers.

clausona now checks whose sign-in each reading was taken with. When it isn't the profile's account,
the row says `other account` in red instead of numbers:

```
    PROFILE             ACCOUNT                         5H         7D
    ──────────────────────────────────────────────────────────────────
    claude:default      me@example.com                  other account
  ▸ claude:work         work@example.com                28% 1h     74% 2d
  other account: signed in to another account — run `clausona login <profile>`
```

The dashboard's panel names the account it is signed in as. Sign in to the right account in your
browser, then run `clausona login <profile>`. Routing skips such a profile until then, and
`clausona doctor` reports it. For Claude, clausona asks Anthropic which account a sign-in belongs to
once per token. For Codex, `auth.json` already says so. (#207, #208)

## Plugin updates reach every profile

A plugin you install, update or uninstall in one profile now reaches your other profiles the next
time each of them starts. Before, `claude plugin update` changed only the profile it ran in, and the
others kept loading the old version. (#204, #205)

## Updating

Choose Update on the dashboard, or run `clausona update`. Your shell hook hasn't changed, so open
shells keep working.

The routing plugin's skill now knows the new skip reason, `other-account`. To pick it up:

```bash
claude plugin marketplace update clausona
claude plugin update routing@clausona
```

On 0.3.0-beta or earlier, which can't update itself, run the installer again:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
