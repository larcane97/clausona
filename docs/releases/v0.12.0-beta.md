Until now only the dashboard told you about a new clausona or asked for a star. From this release,
the commands you run can ask too, right under their output, and one key answers.

## Update from any command

When a newer release is out, the next command you run asks:

```
$ csn list
  ...

  ⬆ clausona v0.13.0-beta is available (you have v0.12.0-beta)
  Update now? (Y/n) y
  ✔ Updated v0.12.0-beta → v0.13.0-beta
    Open a new shell to load its shell hook.
```

y or Enter updates, after one more look at GitHub so you get the newest release. Any other key is a
no, and so is no answer within 10 seconds. After a no you aren't asked again for 7 days, even if
another release comes out. Saying no on the dashboard or to `clausona update` counts the same.

No command waits on GitHub for this. Once a day a command checks in the background, and the ones
after it ask from what it found. If your clausona wasn't put in place by the installer, it can't
replace itself, so you get the installer command to run instead of the question.

It only asks after a command that worked, in a terminal. It never asks when the output goes to a
pipe or with `--json`, on CI, or after commands that start Claude Code or Codex, such as
`clausona run`, `claude` and `codex`.

## A star, asked once

Three days after you start using clausona, a command asks once:

```
  ★ Was clausona helpful? A star on GitHub helps others find it.
  Star it now? (y/N) y
  ✔ Starred larcane97/clausona as @you. Thank you!
```

Only y stars it. Enter, any other key or no answer leaves it alone. It is asked once, ever, whether
on the dashboard or after a command, so if the dashboard already asked you, you won't see it again.
The dashboard's popup now asks the same thing: "Was clausona helpful?". If an update and the star
are both due, you get the update first and the star on a later command.

## Updating

Choose Update on the dashboard, or run `clausona update`. From this version on, the next update can
come from any command. Your shell hook hasn't changed, so open shells keep working. The plugins
haven't changed in this release.

On 0.3.0-beta or earlier, which can't update itself, run the installer again:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
