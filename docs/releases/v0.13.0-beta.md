This release has OpenRouter profiles tell OpenRouter that their requests come from clausona.

## OpenRouter's app headers

An API profile on `openrouter.ai` now includes OpenRouter's app attribution headers with every
request:

```
HTTP-Referer: https://larcane97.github.io/clausona/
X-OpenRouter-Title: clausona
X-OpenRouter-Categories: cli-agent
```

OpenRouter uses these headers to count usage by app. Until now, it couldn't tell when a request came
from clausona. The headers only name clausona, not your account, the profile, the model, or your
machine. Profiles on other endpoints send nothing new.

If you want to send your own headers instead, or send none, set `ANTHROPIC_CUSTOM_HEADERS` on the
profile. Setting an empty value sends no headers:

```bash
clausona config claude:gw --set ANTHROPIC_CUSTOM_HEADERS=
```

Because an empty value holds no secret, it no longer triggers the plain-text warning from
`config --set` or `doctor`. (#218)

## Updating

For the `clausona` command, choose Update on the dashboard, or run `clausona update`. Your shell
hook hasn't changed, so open shells keep working, and the next `claude` on an OpenRouter profile
sends the headers.

On 0.3.0-beta or earlier, which can't update itself, run the installer again:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
