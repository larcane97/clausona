This release shows every skill, MCP server and hook your Claude Code and Codex accounts load,
project by project, and lets you turn them off or delete them.

## Extensions

Choose Extensions on the dashboard, or ask from the CLI:

```bash
clausona skills ls                                # what Claude Code and Codex load in this project
clausona skills ls --scope unused --tool claude   # skills not used in 90 days, in every project
clausona mcp show github                          # one server: what it runs, which accounts start it
```

On the screen, Claude and Codex are tabs, with Skills, MCP and Hooks under them. The first line
on the left names the project you are in and counts what loads there. Its table is grouped by
where each item comes from: the project, the folders above it, Global, Cloud and plugins. Each
place has its own line below, which also lists what doesn't load, such as a copy another one
hides or an item that is turned off. `p` lists your other projects, and typing narrows the list.

## Turning things off and deleting them

```bash
clausona skills off old-skill --dry-run      # what turning it off here would change
clausona mcp off github --everywhere         # off in every project
clausona skills rm old-skill                 # delete it, after a backup
clausona skills undo                         # put back the last change
```

Every change shows what it will do and asks first. A deleted folder goes to
`~/.clausona/backups/extensions/`, and `undo` puts it back. For a Claude skill,
`clausona skills visibility <name> name-only` keeps it installed but shows Claude only its name.
If git tracks the file in a project, the change is refused unless you add `--tracked`, because it
would change the repo.

On the screen the same changes are keys: `space` turns a row off or on here, `g` everywhere, `d`
deletes, `x` marks several rows and `u` undoes. A dialog asks before anything changes.

With `--json`, every command prints JSON, plans and errors included, so an agent can drive it.
Everything is in [docs/extensions.md](https://github.com/larcane97/clausona/blob/main/docs/extensions.md).

## Fixes

- An unknown command such as `clausona plugins` printed the whole help and exited 0. It now
  prints `Unknown command 'plugins'. Run clausona --help.` and exits 2.

## Updating

Choose Update on the dashboard, or run `clausona update`. Your shell hook hasn't changed, so open
shells keep working.

On 0.3.0-beta or earlier, which can't update itself, run the installer again:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
