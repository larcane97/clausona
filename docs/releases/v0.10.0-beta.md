The dashboard and every other screen now fit your terminal, however many profiles, findings or
routes you have. There is also a way to star clausona on GitHub, from the dashboard or the shell.

## Every screen fits your terminal

A screen taller than the terminal used to lose its top. A profile with many doctor findings, a
long profile list or a short window was enough. The terminal was cleared and drawn again on every
key, and the title and the selected row ended up above the top of the window, where scrolling
back didn't reach them. In an 80×24 window the dashboard opened with its title gone.

Now each screen keeps to the terminal's height:

- Lists scroll with the cursor and say how many rows are above and below, as `↑ 3 more` and
  `↓ 12 more`. That covers the dashboard menu, Profiles, Health check, Initialize, Add, and the
  routes, dir rules and budgets in Routes.
- The profile panel beside the list shows the findings that fit and counts the rest, as
  `… 9 more in Health check`. Health check shows the ones that fit there too, and
  `clausona doctor` lists them all.
- The Usage table scrolls with ↑↓. The period is ←→, as the hints say. ↑↓ used to change it too.
- In a short terminal, panels and forms give up their blank lines first, then the parts you can
  do without, such as the panel's usage or the API form's hints. Warnings and errors stay.

## Star clausona on GitHub

If clausona is useful to you, a star helps other people find it. The dashboard has a
`★ Star on GitHub` item, and the shell has a command:

```bash
clausona star
```

It stars clausona through `gh` when gh is signed in to github.com. Otherwise it opens the
repository's page in your browser, where you press Star yourself. Over SSH, or with no display, it
prints the address.

After you have used the dashboard for three days, it asks once. Nothing is starred unless you
choose Star, and it never asks again. Whether it has asked is kept in `~/.clausona/notices.json`.

## Updating

Choose Update on the dashboard, or run `clausona update`. Your shell hook hasn't changed, so open
shells keep working.

On 0.3.0-beta or earlier, which can't update itself, run the installer again:

```bash
curl -fsSL https://github.com/larcane97/clausona/releases/latest/download/install.sh | bash
```

```powershell
irm https://github.com/larcane97/clausona/releases/latest/download/install.ps1 | iex
```
