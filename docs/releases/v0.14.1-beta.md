This release doesn't change clausona itself. Apart from the version number, `clausona.js` is the same as in 0.14.0-beta.

## npm

0.14.0-beta went to npm by hand. From this release on, the release workflow publishes each new version to npm itself, at the same time as the GitHub release, so `npm install -g clausona` gets a new version on the day it comes out. (#220)

## Build

The release and CI workflows now use the Node 24 versions of GitHub's checkout and setup-node actions and of pnpm's setup action. The old versions ran on Node 20 and printed a warning on every run. (#225)

## Updating

You don't have to update for this release. If you want to, choose Update on the dashboard or run `clausona update`. If you installed with npm, run `npm install -g clausona@latest`.
