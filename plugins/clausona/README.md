# clausona (old plugin name)

This is the old name of [superset-fleet](https://github.com/larcane97/clausona/tree/main/plugins/superset-fleet).
In Claude Code, installing it installs superset-fleet; in Codex it carries no skill. Install
`superset-fleet@clausona` instead, or `herdr-fleet@clausona` or `orca-fleet@clausona` for herdr or
Orca. If you installed this one before, run `claude plugin install superset-fleet@clausona` once.
